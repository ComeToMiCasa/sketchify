A PostCSS plugin

Sketch your CSS.
Keep your layout.

postcss-sketchify turns the borders, fills and underlines of plain CSS into hand-drawn sketches at build time. Every element keeps its position and size, down to the pixel.

npm i -D postcss-sketchify
View on GitHub npm package

Three promises

0px

layout shift. Borders keep their width; only their colour turns transparent.

0 KB

of JavaScript at runtime. The drawings are SVG, written into your CSS.

+2–11 KB

gzip for a typical page. A budget warning tells you when it grows.

How it works

  1. 1

    Write plain CSS

    Borders, backgrounds and underlines, the way you always do.

  2. 2

    Build

    The plugin draws each border once with Rough.js and writes it into the CSS as border-image.

  3. 3

    Ship sketches

    Neighbours get different drawings, so a list of cards never looks stamped.

What gets drawn

Borders

Any width in px, square or rounded up to 32px.

1px 2px 4px 12px

Single lines

One side of a border, or an hr. The ends always reach the edges.

  • Dividers in a list
  • However long it gets
  • Still reach both ends

Underlines

Inline links get a line under every line of text: this link wraps over more than one line on a narrow screen.

Fills

Add --sketch-fill next to a background colour.

rough marker hatch

States

Hover keeps the same shape in another colour.

Roughness

Three presets or any number. Switch them above: the layout does not move.

subtle · normal · messy

Good to know

  • Browsers: Chrome, Edge, Safari and every browser on iOS. Not Firefox.
  • Your own CSS: hand-written stylesheets, not CSS frameworks.
  • Fonts stay yours: the plugin never changes fonts. The handwritten letters on the sketched side are this page's own choice (Monaspace Radon, metric-compatible with Monaspace Neon).
  • Colours at build time: literal colours or variables the plugin can resolve, including dark mode media queries.
