border-image 경계 테스트

A 방식에서 확인이 필요한 두 가지를 재현했어요. 판별하기 쉽도록 손그림 대신 단색 그림을 써요. 빨강은 테두리 조각, 파랑은 가운데 채움(fill)이에요. "Chromium 측정"은 제가 headless Chromium에서 픽셀을 읽어 확인한 결과예요. Safari에서는 같은 그림이 나오는지 눈으로 비교해주세요.

3. 테두리 없는 요소에서 border-image가 그려지는지

거친 단색이나 형광펜을 border: none인 요소에 쓰는 경우예요. border-image-width를 px로 따로 주면 원래 테두리 두께와 상관없이 그려지는지 봐요.

테두리 조각가운데 채움

3A기준: 투명 테두리 10px

border: 10px solid transparent;
기대: 빨간 테두리 + 파란 가운데

3Bborder: none

border: none;
border-image-width: 10px;
기대: 3A와 같으면 통과

3C두께 0 투명 테두리

border: 0 solid transparent;
border-image-width: 10px;
기대: 3A와 같으면 통과

3Dborder: none + 바깥으로 6px

border: none;
border-image-width: 10px;
border-image-outset: 6px;
기대: 빨강이 상자 바깥 6px까지

4. 부모의 overflow가 바깥으로 나간 선을 자르는지

대상 요소는 그림이 상자 바깥으로 6px 나가요(border-image-outset). 점선이 부모 상자이고, 대상은 부모 안쪽 끝에 딱 붙어 있어요. 4F는 부모가 아니라 요소 자신에 overflow: hidden이 있는 경우로, 이미지가 든 둥근 카드에서 흔한 패턴이에요.

4A기준: 부모 overflow 없음

부모 { overflow: visible }
기대: 바깥 6px 보임

4B부모 overflow: hidden

부모 { overflow: hidden }
예상: 바깥이 잘림

4C부모 hidden + 여백 8px

부모 { overflow: hidden;
       padding: 8px }
기대: 여백 안이라 안 잘림

4D부모 overflow: clip + 여유 8px

부모 { overflow: clip;
       overflow-clip-margin: 8px }
기대: 여유만큼 안 잘림 (대안 후보)

4E부모가 스크롤 영역

부모 { overflow: auto }
예상: 바깥이 잘림

4F요소 자신이 overflow: hidden

요소 { overflow: hidden;
       border-radius: 12px }
기대: 자기 테두리 그림은 안 잘림
