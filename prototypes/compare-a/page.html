현재 방식 vs A 방식

현재 방식은 가상요소에 mask로 그리고 색은 CSS 변수로 칠해요. 그래서 요소에 position: relative와 isolation: isolate가 필요해요. A 방식은 border-image와 배경으로 요소 자체에 그리고, 색은 SVG에 고정해요. 두 열의 HTML은 같아요.

1모양

같은 모양이 나오는지 확인해요. A에서 거친 단색은 테두리와 채움을 SVG 하나에 같이 그리고(border-image의 fill), 빗금은 배경 이미지로 깔아요.

2absolute 자식: 메가 메뉴

점선 상자가 position: relative인 내비게이션 바예요. "캠페인" 메뉴 항목은 테두리가 있어서 손그림이 되고, 원래 position이 없어요. 펼쳐진 메뉴는 내비게이션 바 전체 너비로 펼쳐지도록 작성했어요. 왼쪽 원본이 정답이에요.

3옆 요소 위로 올라가는 툴팁

첫 번째 카드 안의 툴팁(z-index: 10)이 옆 카드 위로 넘어가야 해요. 현재 방식은 카드마다 쌓임 맥락이 생겨서, 나중에 그려지는 옆 카드가 툴팁을 덮어요.

4hover 색 변경

마우스를 올리면 테두리는 브랜드 색, 채움은 밝은 노랑으로 바뀌어요. A는 hover용 SVG로 갈아끼워요. "첫 hover 다시 보기"를 누르면 A의 hover SVG를 새로 만들어서, 처음 바뀔 때 테두리가 잠깐 비는지 다시 확인할 수 있어요.

5실행 중 색 변경

위 컨트롤의 브랜드 색을 바꿔보세요. 현재 방식은 CSS 변수를 따라 바로 바뀌고, A는 빌드 때 정한 색에 머물러요. 다크 모드는 A도 동작하는데, 미리 다크용 SVG를 따로 만들어둬서 가능한 거예요.
